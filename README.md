# 💰 账单体检 bill-checkup

导入微信 / 支付宝账单，自动清洗、自动分类，用看板告诉你钱花在哪、哪些钱可以省。

> 面向大学生的个人记账分析工具。数据只在本地处理；只有规则认不出的少量商家名会（可选地）发给 AI。

## 能做什么

| 功能 | 说明 |
|---|---|
| **导入** | 直接读取微信（.xlsx）、支付宝（.csv）官方导出的账单，处理 GBK 编码、开头的说明行、金额里的 ¥ 等格式问题 |
| **自动清洗** | 去掉交易关闭、全额退款；部分退款按实际花费扣除；**跨月退款**（上个月买、这个月退）抵扣本月支出；重复导入自动去重 |
| **自动分类** | 规则优先 + DeepSeek 兜底，10 个分类；「吃喝」大类、「必要 / 弹性」两种角度 |
| **流水** | 按时间、平台、收支、分类筛选和搜索；按商家 / 分类汇总；手动改分类、标记「不计入」（代付、借钱），修改自动保存 |
| **看板** | 弹性支出占比、比上月变化、每月 / 每日支出（必要 vs 弹性）、分类和商家排行、消费日历、自动小结 |
| **示例数据** | 没有账单也能体验：一键生成虚构大学生半年的账单（格式和真实导出一样） |

## 分类效果（核心亮点）

在 **100 笔真实交易**上人工标注正确分类，对比三种方案：

| 方案 | 准确率 | 覆盖率 | 调用 AI | 费用 |
|---|---|---|---|---|
| 纯规则 | 57% | 69% | — | — |
| 纯 AI | 83% | 100% | 62 个商家 | ¥0.012 |
| **规则 + AI** | **87%** | **100%** | **16 个商家** | **¥0.003** |

- 规则（179 条，Excel 可编辑）先分，命中时 83% 准确；认不出的（共享单车、英文品牌名、个人小店扫码）交给 AI
- 「规则 + AI」比纯 AI 更准，API 成本少约 70%
- 评测纪律：写规则和 AI 提示词时都**没有看评测集**，避免分数虚高；详见 [docs/评测结果.md](docs/评测结果.md)

## 隐私设计

- 账单只在本地处理，真实账单放在 `private/`，不上传 GitHub
- 发给 AI 的只有**商家名、商品名、平台分类**；不发时间、金额、支付方式；转账、红包由规则处理，朋友的名字不会外传
- 同一商家只问一次；没有设置 API Key 时完全不联网
- 手动修改只按交易编号保存在本地，不存交易内容

## 产品迭代

所有产品决策、测试反馈和修复记录在 [docs/改进清单.md](docs/改进清单.md)，例如：

- 测试发现「餐饮」和用户心里的「吃」不一样 → 新增「吃喝」大类
- 「花了多少」不如「哪些可以省」有用 → 新增「必要 / 弹性」视角
- 金额用 ¥ 被看成日元 → 统一显示为「元」

## 本地运行

```bash
uv sync
uv run streamlit run app.py
```

可选：把 DeepSeek API Key 填进 `.streamlit/secrets.toml`（不会上传），导入时打开「用 AI 补全」。

## 开发

```bash
uv run pytest                                  # 120+ 个测试（AI 用假客户端，不联网）
uv run python scripts/make_label_sheet.py      # 从 private/ 的账单抽样生成标注表
uv run python scripts/evaluate.py              # 评测规则 / AI / 规则 + AI
```

```
app.py            首页
pages/            导入、流水、看板、报告
app_state.py      页面共用的导入、修改操作
core/             业务逻辑（不含界面，可单独测试）
  parse.py          解析微信 / 支付宝账单
  clean.py          清洗：退款、跨月退款、去重
  classify.py       规则分类（规则表 rules.csv）
  ai_classify.py    AI 分类（DeepSeek）
  overrides.py      手动修改的保存与套用
  dashboard.py      看板计算
  demo.py           示例数据生成
scripts/          标注表、评测脚本
tests/            测试
docs/             改进清单、评测结果
private/          真实账单和本地数据（不上传）
```
