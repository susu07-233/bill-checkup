# 账单体检 · 设计规范（给 Figma 用）

> 风格：奶油白 + 鼠尾草绿的「生活账本」。下面的数值都是网站现在实际用的，
> 来源：`.streamlit/config.toml`（主题）和 `styles.py`（卡片、小票、柔光）。
> 在 Figma 里先把「颜色」「文字」建成样式（Styles），再把卡片、按钮做成组件（Components）。

## 2. 文字（建成 Text Styles）

字体：英文和数字用 **Inter**，中文用 **微软雅黑**（Mac 上是苹方）。小票金额用等宽字体（Consolas）。

| 名字 | 字号 | 粗细 | 例子 |
|---|---|---|---|
| 大标题 | 40 | Bold 700 | 没买什么，钱都花哪儿了？ |
| 页面标题 | 32 | Bold 700 | 消费看板 |
| 卡片标题 | 15 | Semibold 600 | 每月支出 |
| 大数字 | 26 | Semibold 600 | 13,674.10 元 |
| 小票金额 | 34 | Semibold 600，等宽 | 172.70 元 |
| 正文 | 15 | Regular 400 | 把微信和支付宝的账单放在一起… |
| 说明 | 13 | Regular 400，次要色 | 点问题看答案… |

行高：正文约 1.6 倍。

## 4. 组件（建成 Components）

- **按钮**：主按钮（深绿底、白字）、次按钮（白底、细描边、深色字）、文字按钮（无底无边、带 ↗ 图标）。
- **卡片**：白底 + 描边 + 阴影 + 圆角 16，里面左上角放卡片标题。
- **数字卡片**：小标题（说明字）+ 大数字 + 下方趋势小图。
- **小票**：白纸、顶部「账单体检 / 小林的 10 月」、标题、等宽大金额、说明、虚线、明细行（左名字右金额）、「其他 N 家店」、底部锯齿。
- **侧栏导航项**：图标 + 文字，选中时底色 `#DFE6DC`。
- **标签（badge）**：「AI 已连接」浅绿底、深绿字。

## 5. 页面结构

**首页（电脑）**：左侧栏 | 主区左边（小字 → 大标题 → 一句说明 → 3 个问题按钮 → 两个链接）| 主区右边（小票卡片）；最下面「它是怎么做到的？」折叠栏。右上角一层很淡的绿色柔光。

**看板（电脑）**：标题 + 右上角时间选择 → 第一行（总支出卡片 2 份宽 | 最值得看的发现 3 份宽）→ 三个次要数字 → 「还有这些发现」卡片 → 问问你的账单 → 必要 vs 弹性 | 每月支出 → 每周支出 → 工作日、周末、节假日 → 各分类 | 前 10 商家 → 消费日历。
